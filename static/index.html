In-Sample (IS) Replica (purple dashed) — a single set of ETF weights fitted on all available fund history at once. These weights are NOT truly out-of-sample: the optimization saw the same data it is being evaluated against, so it will appear to track the fund more closely than is realistic going forward. Compare it to the Rolling OOS Replica (orange) to see how much lift comes from refitting vs. a static style snapshot. The IS weights also power the ETF allocation bar chart.
